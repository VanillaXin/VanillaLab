# 香草芯 · Vanilla Xin

通过本地 HTTP 服务打开 [index.html](index.html) 浏览设定；编写格式与本地文件模式说明见站内导航“编写 → 编写说明”。

## 世界与主舞台

- 世界处于科技与魔法同时高度发达的现代社会。
- 人类与植物精灵曾经历人灵战争，并以人灵共生协定确立共同发展的制度基础。
- 香草芯源自战后早期共生研究机构，如今拥有多个研究院区。
- 主舞台为**香草芯生命科学研究院 · 桜川院区**。
- 芯禾、咲夜、绯咲、秋音、曦、白露与若玲长期生活在桜川。

## 核心规则

- 现代魔法拥有六个主要等级，等级用于描述理论、资格、权限、难度与专业阶段。
- 魔力可以转化为较稳定的**液态魔力**，用于储存、运输与工程调度。
- 现有魔力转换效率处于**中等水平**，已经能够实用化，仍有很大的提升空间。
- 植物精灵是拥有完整人格、自主权和社会身份的智慧生命。
